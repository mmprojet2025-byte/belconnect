# Première version — v0.1.0-alpha.1

Date : 31 octobre 2026. Statut : **alpha de développement**.

## Périmètre figé

Cette version rassemble le web de gestion, le mobile Expo connecté, les espaces et groupes, les activités et projets, les participations, la messagerie mobile, les notifications et les réglages du compte. Elle comprend les plafonds Starter/Pro, la demande de passage Pro sans activation automatique, les demandes d’espace et leur examen propriétaire.

Les derniers changements comprennent l’inscription gratuite simple aux projets, la visibilité des inscriptions existantes, la recherche dans les participations, la refonte profil/réglages, les notifications web cliquables et les premiers contrôles supplémentaires de suppression de compte.

## Limites connues

- Paiements réels non ouverts ; recette Stripe complète à effectuer.
- Audit de sécurité exhaustif et validation juridique non réalisés.
- Textes RGPD/confidentialité encore provisoires ; suppression par désactivation/anonymisation avec conservations possibles.
- Limitation des confirmations de suppression en mémoire ; tests dédiés et concurrence à compléter.
- Notifications systématiques liées aux inscriptions et modifications à compléter.
- Recette complète web/mobile à rejouer, notamment les échecs de navigation précédemment observés.
- Le tag est un instantané du code et de la documentation, pas une sauvegarde de la base, des secrets ou des médias locaux.

## Vérification de cette livraison documentaire

La livraison modifie la documentation uniquement. Vérification des liens Markdown locaux de la nouvelle documentation et du diff Git ; aucune nouvelle campagne complète de tests applicatifs n’est revendiquée. Les tests ciblés d’authentification web/mobile avaient passé lors du durcissement précédent.
